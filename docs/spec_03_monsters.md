# 3. 怪物与感知机制（规格稿 v1）

> 归属：AI 设计位。所有条目可配置化，数值进 `data/monsters.json`，不得硬编码。
> 核心规则：开局不揭示怪物类型；玩家仅凭**声音标识 / 影子 / 行为痕迹**推断。

## 3.1 首发名单（4 只）

| ID | 名称/代号 | 强感知（1–2） | 弱感知（盲区） | 行为特征 | 克制手段 | 声音标识（频段） | 出现圈层 |
|----|-----------|----------------|----------------|----------|----------|------------------|----------|
| M01 | 拾荒者 `scavenger` | 动态视力（移动目标 24m） | **静止不动即近乎隐形**（<0.3m/s 位移无法锁定） | 慢速巡逻，沿资源点游走；发现目标后直线扑击，不绕障 | 蹲伏静止、关灯、绕视线外 | 金属拖拽 120–200Hz 锯齿 + 低频哼声 | 内圈 70% / 外圈 30% |
| M02 | 循声者 `listener` | 听觉（脚步 30m / 开枪 80m / 任务噪音 50m） | **强光短暂致盲 2.5s** | 循声定位，到点后范围砸击 6m；对移动声源持续追踪 | 蹲行（噪音 −70%）、投掷物调虎离山、手电直射 | 高频耳鸣脉冲 4–6kHz + 回声敲击三连 | 全图 |
| M03 | 影织者 `shadeweaver` | 视觉（低光/阴影区感知 ×2） | **强光区**内感知 −80%，不能进入直射光斑 | 沿阴影边缘潜行，绕开光源；追踪时影子拉长可先于本体可见 | 制造光斑（照明棒/车灯）、贴墙走亮区 | 布料摩擦 800–1.5kHz + 20–40Hz 低频嗡鸣 | 内圈 40% / 外圈 60% |
| M04 | 破门者 `breaker` | 嗅觉/热源（穿墙 12m 探测） | **水/雨区**追踪失效；重新锁定需 6s | 破坏掩体与门（3s/扇），缓慢但不可阻挡；进入高怒气后直冲撤离点 | 引至水域、临时封门、牺牲掩体换时间 | 沉重脚步 60–90Hz + 液压泄压嘶声 | 压迫期后全图 |

## 3.2 混音可区分约束（硬性）

| 怪物 | 主频段 | 次要特征 | 静音/远场识别 |
|------|--------|----------|----------------|
| M01 | 120–200Hz | 锯齿拖拽，节奏不规则 | 远场仅剩低频哼声 |
| M02 | 4–6kHz | 脉冲间隔 1.2s，回声三连 | 远场高频先衰减，改为敲击回响 |
| M03 | 800–1500Hz | 持续摩擦，随距离变调 | 远场仅剩 20–40Hz 嗡鸣 |
| M04 | 60–90Hz | 脚步 0.8s 周期 + 泄压嘶声 | 远场脚步主导 |

验收：任意两只同屏混音后，ABX 盲测识别正确率 ≥ 80%（测试用 `audio.abx` 模式）。

## 3.3 阶段化刷新与怒气联动（C 方案）

| 阶段 | 时间 | 同时在场上限 | 怒气底值 | 行为倾向 |
|------|------|--------------|----------|----------|
| 摸索期 | 0–15min | 1 | 0–20 | 巡逻为主，远离出生点 |
| 压迫期 | 15–40min | 2 | 20–60 | 主动搜寻，移速 +10%，开始破坏掩体 |
| 崩溃期 | 40–60min | 3 | 60–100 | 持续追击，感知半径 +30%，外观/音频变奏 |

怒气公式（服务端权威，每秒结算）：
```
anger = clamp(0..100,
    base_rate * t
  + Σ task_jump   (任务节点：+8/节点)
  + Σ damage_jump (玩家造成伤害：按伤害值 × 1.2，单次上限 +18)
  - calm_rate * (30s 无交火)
)
```
- `base_rate = 0.11/s`（约 9 分钟 +60）
- 击杀/救援成功：−6（鼓励有效协作）
- 高怒气（≥80）触发 `enrage_mutation`：外观变化 + 音频层叠加，**类型仍不揭示**


## 3.5 验收口径

- 画面/日志：怪物类型在**任何 UI 与日志**中不可出现（服务端 debug 面板除外）。
- 服务端证明：感知判定、伤害、怒气全部由服务端计算并可回放审计。
- 帧耗时：4 怪同时激活完整行为树时，服务端 AI 预算 ≤ 2ms/tick（20Hz）。
- 可玩性：静止不动的玩家被 M01 发现率 < 5%；被 M02 在 30m 外开枪后 10s 内到达率 > 90%。
